# UltraRando — setup

1. Install the Everest mod `UltraRando`.
2. Put `ultrarando.apworld` in Archipelago's `custom_worlds` folder and generate with a YAML
   whose `game` is `UltraRando`.
3. In Celeste, open the mod settings, enter the server, slot name and password, then `Connect`.

Offline test: generation also writes `<seed>_cmr_slot_data.json`; load it in game with the console command
`cmr_offline <path>`.
