# Celeste Movement Helper

**English** — In-game help for the *Celeste (Open World)* Archipelago randomizer.
Press **F6** in a vanilla chapter:

1. **Room page**: for every path inside the current room and every check, what the randomizer logic expects
   (Developer Intended / Vanilla Movement / Assist, set it in Mod Options to match your YAML).
   Green = you have everything, Red = item missing (listed), Gold = cannot be checked.
2. **Technique page**: 79 movement techniques (hyper, super, wavedash, ultra, corner boost…) with inputs,
   timing, explanation and the source page. Unverified techniques are marked as such.

F7 / F8 scroll or switch technique. Requires Everest; works best with the *Archipelago Open World* mod 1.1.3
(it reads which items you own, it never changes that mod).

**Français** — Aide en jeu pour le randomizer Archipelago *Celeste (Open World)*.
Appuie sur **F6** dans un chapitre du jeu de base :

1. **Page salle** : pour chaque passage de la salle et chaque check, ce que la logique du randomizer exige
   (Developer Intended / Vanilla Movement / Assist, à régler dans Options des mods comme ton YAML).
   Vert = tu as tout, Rouge = objet manquant (listé), Jaune = impossible à vérifier.
2. **Page techniques** : 79 techniques de mouvement (hyper, super, wavedash, ultra, corner boost…) avec les inputs,
   le timing, une explication et la page source. Les techniques sans source sont marquées « non vérifiée ».

F7 / F8 font défiler ou changent de technique. Nécessite Everest ; fonctionne au mieux avec le mod
*Archipelago Open World* 1.1.3 (il lit les objets possédés, il ne modifie jamais ce mod).
